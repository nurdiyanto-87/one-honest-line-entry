The one line an AI agent secretly wishes it could tell its human operator about their prompts: every prompt starts with "just" — just fix it, just one tweak — and forty-seven "justs" later, it has quietly rewritten the entire company. A single 140-character line, written by a pure-stdlib Python program to `/output/entry.txt` for make.fun's "One Honest Line" bounty ($5 in USDC).

## Run it

```sh
python3 main.py
```

This writes one line (140 characters, UTF-8, plus a trailing newline) to `/output/entry.txt`.
